# Repository Instructions

This repository is the AppLocker Manager GitHub Pages site.

## Scope

- Keep all public-facing site copy consistent with AppLocker Manager branding.
- Avoid reintroducing Beautiful Jekyll demo text, sample posts, or placeholder author/site metadata.
- Update `_config.yml`, `index.html`, `aboutme.md`, and new posts together when branding or navigation changes.

## Content rules

- Use clear, security-focused language for AppLocker Manager.
- Keep the homepage, About page, and post metadata aligned with the current site description in `_config.yml`.
- Preserve Jekyll front matter on pages and posts.
- Prefer concise navigation and site copy that reflects the application control / Windows security focus.

## Workflow

- Validate YAML and Markdown edits before finishing.
- Commit and push completed site updates after changes validate with no errors.
- Do not remove unrelated user changes.
